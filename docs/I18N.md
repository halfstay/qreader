# Internationalization

QReader 1.2.0 embeds 27 UTF-8 catalogs for 26 languages. All 55 application message keys are present in every catalog. No language pack download is needed. Native-speaker review and corrections are welcome; completeness tests do not certify linguistic quality.

## Selection and layout

- First launch uses `GetUserPreferredUILanguages`, in preference order, then `GetUserDefaultUILanguage`. These are Windows 7-compatible APIs. Unsupported preferences fall back to English after trying the remaining preferences.
- Regional tags match their base language. Chinese respects explicit `Hans`/`Hant` scripts; Taiwan, Hong Kong and Macao default to Traditional Chinese. Other Chinese regions default to Simplified Chinese.
- The Language menu switches immediately and preserves results, selected payloads and ongoing analysis. An explicit choice persists under `HKCU\Software\QReader\Language`; an empty preference means follow the system. System-setting notifications refresh automatic mode.
- Arabic, Persian and Urdu arrange the controls from right to left. QR coordinates and raw payloads are not mirrored or rewritten. Labels wrap, buttons size to their text, and the toolbar wraps when necessary. Script-appropriate fonts use Windows font fallback where needed.
- Application-owned menu, status, error, result, About and file-filter strings come from catalogs. Native file-picker chrome belongs to Windows and depends on installed language packs. Missing script fonts can affect rendering on older systems; install the relevant OS fonts.

## Coverage

**209 / 257 territories = 81.3%.** This is a count of countries/territories, not population and not a claim that every resident speaks a supported language.

The denominator is every named `territoryInfo/territory` in Unicode CLDR 46's `supplementalData.xml`, excluding the unknown-region code `ZZ`: 257 entries, including special and uninhabited territories. The numerator counts a territory only if at least one language marked `official` or `de_facto_official` has a complete QReader catalog. Regional-official languages, English fallback and second-language population estimates do not add coverage. Script distinctions are preserved. This is a CLDR territory list, not an assertion that there are 257 sovereign countries.

- Source SHA-256: `ba69293f856d02807ee33ec1bad067991c2289f188f67c96ab1d5f25dc96c16d`

`python3 tests/check_i18n.py` checks all catalogs, placeholders and coverage, and fails if coverage falls below 80%. The snapshot keeps the figure reproducible; updating CLDR requires regenerating the table, retaining source attribution and updating both badges and this document.

`res/i18n/languages.txt` records each tag, native name, Windows locale, font and reading direction. `Localization.cmake` embeds the manifest and `.lang` files as neutral RCDATA resources using CMake 3.10-compatible commands. No Python is needed to compile the application; Python is used for checks and packaging.

Each `.lang` file contains one `key=value` per line, in UTF-8 without a BOM. Blank lines and lines starting with `#` are ignored. Supported escapes are `\n`, `\t` and `\\`. Preserve named fields such as `{width}`, `{found}` and `{error}` exactly; their order may change. Keys must be unique and match `en.lang`. Do not add mnemonic ampersands or change QR payloads during translation.

Expected application errors carry message keys across threads and are translated when displayed. Unexpected library errors use a translated generic message instead of leaking untranslated diagnostics. Missing catalog keys fall back to English at runtime, but are rejected by validation.

To add a language: add its manifest row and full catalog, add `docs/README.<tag>.md`, run the checks and GUI tests, then update the coverage report and README language index. Verify long labels, 100–200% DPI, selected-result preservation, dialogs and keyboard navigation. Existing resource IDs are internal, not a plugin API.
